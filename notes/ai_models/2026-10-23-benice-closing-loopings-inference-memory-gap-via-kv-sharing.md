# BeNice! Closing Looping's Inference-Memory Gap via KV-Sharing

Looped architectures scale quality while keeping parameter count fixed by repeatedly passing activations through the same block of layers. During inference, each recurrence generates independent KV-caches, causing memory to grow linearly.
