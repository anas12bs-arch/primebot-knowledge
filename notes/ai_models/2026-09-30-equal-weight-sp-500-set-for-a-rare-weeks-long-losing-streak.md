# Equal-Weight S&P 500 Set for a Rare, Weeks-Long Losing Streak

An equal-weight version of the S&amp;P 500 Index is on track for a seventh consecutive down week. If the weakness lingers through Friday, it would be just the third time the measure has declined for seven weeks in a row ever.
