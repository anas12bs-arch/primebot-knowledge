# VR3D: View-Robust 3D Representation Learning for Aerial-Ground Person Re-Identification

Existing methods attempt to learn view-invariant representations exclusively within the 2D image space, where drastic viewpoint variations cause the learned features to remain coupled with viewpoint bias.
