# Quantifying the added value of human forecaster discussions for tropical cyclone intensity prediction

The National Hurricane Center routinely releases Tropical Cyclone Discussions that offer insights into its tropical cyclone forecasts. This study examines the added value of these discussions for intensity forecasting beyond a set of numerical predictors.
