# More with Less: Efficient Parallel Scientific Code Translation via an Agent-Skill Workflow

Translating parallel scientific codes between HPC programming frameworks is a critical but labor-intensive task. Existing LLM-based approaches rely on fixed sequential pipelines with undifferentiated repair strategies and correctness criteria that do not match scientific computing practice.
